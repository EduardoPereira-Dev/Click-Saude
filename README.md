# Click Saúde

Interface web para um site de saúde voltado a consultas online, desenvolvida com *HTML, CSS e JavaScript*.

## Sobre o projeto

O Click Saúde é um projeto de desenvolvimento front-end que explora a criação de páginas e interfaces para o contexto de consultas online. A proposta é organizar a apresentação do serviço e tornar a navegação clara para quem busca atendimento na área da saúde.

O desenvolvimento envolve a estruturação do conteúdo, a estilização das páginas e a implementação de componentes e interações na interface.

## Objetivo

Aplicar conhecimentos de desenvolvimento web na construção de uma interface para um serviço de saúde, praticando a integração entre HTML, CSS e JavaScript.

## Tecnologias utilizadas

| Tecnologia | Aplicação no projeto |
| --- | --- |
| *HTML* | Estruturação das páginas e organização do conteúdo. |
| *CSS* | Estilização dos elementos e composição visual das interfaces. |
| *JavaScript* | Implementação de comportamentos e interações na interface. |

## Desenvolvimento

- Criação de páginas web para o projeto Click Saúde.
- Desenvolvimento de interfaces com HTML, CSS e JavaScript.
- Implementação de componentes front-end.

## Como visualizar

1. Clone este repositório ou baixe os arquivos pela opção *Code → Download ZIP* no GitHub.
2. Caso tenha baixado o ZIP, extraia os arquivos.
3. Abra a pasta do projeto no Visual Studio Code para explorar o código.
4. Abra o arquivo HTML da página inicial em um navegador para visualizar a interface.

## Experiência prática

O projeto proporcionou experiência na construção de páginas e componentes, na organização do conteúdo com HTML, na estilização com CSS e na aplicação de JavaScript às interfaces web.
